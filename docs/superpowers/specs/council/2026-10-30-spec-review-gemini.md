| 1 | blocker | §6, §7, §12 | `install(app)` decides activation once at call time and permanently mounts a 404 dummy sub-app if inactive. At import time, no reloading supervisor exists, so conservative detection evaluates to false, permanently disabling sharpit. Furthermore, uvicorn's reload supervisor and `--workers` supervisor both launch worker processes via identical `spawn.Process(target=subprocess_started)`. Inside the worker, `sys.argv` (which becomes `['<string>', '--multiprocessing-fork', ...]`) does not contain `--reload` or `--workers`, making conservative stdlib detection impossible without inspecting caller stack frames up to `uvicorn.Config`. | Evaluate activation lazily (during FastAPI lifespan startup or on first request) rather than locking in 404 at `install()` import time. Pin the exact detection hierarchy: (1) check `sys.argv` for `--reload` or `fastapi dev`; (2) walk stack frames from `install()` looking for a `uvicorn.Config` instance and inspect `config.should_reload`; (3) support explicit `SHARPIT_ENABLED=ON` or `SHARPIT_PROFILES=dev`; (4) default to fail-closed if ambiguous. |
| 2 | blocker | §6, §7 | In FastAPI, `CORSMiddleware` added to the host application wraps all routes, including mounted sub-apps. The request arrives from loopback, passes the Host check, and bypasses the cross-site write check (which only guards non-safe methods). Verdict: The spec captures the BootUI surface well, but contains six critical blockers: call-time activation misses dev servers; host-wide CORS exposes sensitive GET data; default proxy headers allow auth bypass; defaultValue leaks secret fallbacks; Pydantic Settings destroys config provenance; and dismissal endpoints are missing.
The Python runtime differences (Starlette mounts, `loggerDict.PlaceHolder`, missing APIRoute metadata, CVSS vector parsing) require explicit specifications rather than hand-waving to "nearest attribute".
Resolve blockers #1–#6 and pin the introspector derivations before handing the spec to autonomous build agents.
