| 1 | blocker | §7 guard, source check | The source check would read `scope["client"]`, but uvicorn rewrites that from `X-Forwarded-For`. `proxy_headers=True` is the default, and `forwarded_allow_ips` comes from `$FORWARDED_ALLOW_IPS`, default `127.0.0.1,::1` (verified in uvicorn 0.53.0 `config.py:225,363`). Two consequences. First, with `FORWARDED_ALLOW_IPS=*`, which is common in Docker images, any client that sends `X-Forwarded-For: 127.0.0.1` becomes "loopback" and skips the token. Second, a local reverse proxy or tunnel that sends no XFF makes every remote request loopback. BootUI's `LocalhostGuard` explicitly uses "the real socket address, never a forwarded header" (L23-26), and the spec does not carry that rule over. | Say in the spec that the peer is the transport peer. The ASGI app can't recover it after uvicorn rewrites it, so: when `Forwarded`, `X-Forwarded-For` or `X-Real-IP` is present and `trusted_proxies` is empty, treat the source as untrusted (403, or token required). Add tests with `FORWARDED_ALLOW_IPS=*` plus a spoofed XFF, and with a header-less tunnel (Host rewritten to localhost). |
| 2 | blocker | §6 adapter, §7 cross-site | FastAPI's `CORSMiddleware` wraps the whole app, sharpit's mount included. The request passes the loopback and Host checks, the cross-site check only covers writes, and the host adds `Access-Control-Allow-Origin`. In BootUI, Spring CORS is per-mapping, so this gap didn't matter there. | Make the sub-app reject **any** method that has `Sec-Fetch-Site: cross-site`, or an `Origin` whose host differs from `Host`, and log it in §13 as a deviation. Verdict: the contract is faithfully extracted, but the Python safety mapping isn't safe yet. Two holes need fixing before any build: XFF-rewritten `scope["client"]` (#1) and host-wide CORS exposing GETs (#2). The dev-server signal (#3) needs a concrete algorithm, and profile resolution (#4, #5) needs pinned precedence. Config provenance (#6-#8) and bean naming (#9) are underspecified in ways that will produce wrong data, not crashes, so contract tests won't catch them. Fix #1-#9 and add the endpoint table (#11) before writing the plan. Everything else can be settled as the plan is written.
