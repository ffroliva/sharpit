Verdict: The spec captures the broad panel set but leaves high-risk behavior open exactly where Python lacks BootUI’s framework guarantees.
The production-safety, source-provenance, MCP transport, and dependency-graph rules are not yet executable acceptance criteria.
Resolve blockers and define per-route contracts before deriving the implementation plan.
