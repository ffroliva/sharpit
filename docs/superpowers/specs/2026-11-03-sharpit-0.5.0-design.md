### 4.2 App-source layer `engine/appsource.py` (F5a; council required)

The riskiest new surface: it reads host files. stdlib `ast`, `tokenize`, `os`, `stat` only; never imports or executes.
**One resolver** for every source reader: `resolve_package_root(app, modules)` reads module globals in `sys.modules`
only (the G6 autodetect read; `type(app).__module__` would name FastAPI), else `settings.app_package` resolved through
`sys.modules` only (never `find_spec`, which imports parents). A single-module app indexes that file only; an app whose
module is `__main__` is `NOT_SCANNED` with a reason. Containment: `realpath` + `commonpath` against the root (so Windows
junctions and symlinks cannot leave it), `S_ISREG` before opening (no FIFO or device), `RecursionError`/`MemoryError`/
`SyntaxError`/`UnicodeDecodeError` → limitations. Bounds `max_files` 2,000, `max_file_bytes` 512 KiB. Runs in a
worker thread with a wall budget; the `SourceIndex` is not retained after the scan, only the report dict is cached.
**Config's getenv scan moves onto `appsource`** (`collectors/config/getenv_scan.py` → `engine/appsource.py` helpers;
config imports the engine), so config and the advisors resolve the same root; config's lazy scan on its first GET is
0.3.0 behaviour and stays, recorded as the one exemption from the "no source file opened on a GET" rule (§14).

### 5.0 Read-only database access for MySQL and SQLite (replaces 0.4.0 §6.4's MySQL paragraph)

On `main`, `bounded_read_only` refuses every dialect except PostgreSQL (`sqla.py:612-613`), and `sqla.py:644` is
inside `bounded()`, which sets a timeout only. F5b adds, in `engine/sqla/readonly.py`, after the move commit and with
its reds: **MySQL/MariaDB** `START TRANSACTION READ ONLY` with the session `max_execution_time`
(MariaDB `max_statement_time`) and `innodb_lock_wait_timeout`, verified by `SELECT @@transaction_read_only` (or the
in-transaction check) before any catalog SQL, autocommit refused, `ROLLBACK` and the session values restored in
`finally`, the connection invalidated if the restore fails; **SQLite** `PRAGMA query_only = ON`, verified, restored in
`finally`; any other dialect stays `ReadOnlyUnavailable`. A-mysql and A-dbadv-1 call only `run_db_read(read_only=True)`;
a spy test proves `bounded()` is never their entry point.
