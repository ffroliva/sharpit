# sharpit 0.10.0: decisions record

0.10.0 stays on BootUI 2.5.0 for its ported panels and takes one security change from BootUI 2.6.0 (GitHub credentials
bound to the repository host). This file records the maintainer's rulings and the defaults taken during the 0.10.0
lanes (2026-11-24 to 2026-11-28), so they outlive the working notes.

## Moved to the next release

The release is accepted with these gaps; each has an issue on the 0.11.0 milestone.

- **Flask console after slice 1** (#348). #260 closed for the console contract slice (#331).
- **API route parity after phase 1** (#347). #300 closed for the inventory phase (#336).
- **Journal sources and insight kinds** (#299), **masked exception message in swallowed-exception findings** (#253) and
  **trace and journal masking on the matrix path** (#302): nothing of these shipped, so each issue moved whole.
- **Security sinks for SQL statements and outbound URLs.** 0.10.0 checks commands and file paths only; the later plans
  of the sinks lane are not in this release.
- **Masking of whole test names.** The masker can blank a whole test identifier rather than only the secret in it; the
  change touches a safety path and goes through prediction and council review first.
- **The BootUI 2.6.0 port.** The 2.6.0 delta is recorded; its remaining items, including a stricter cross-site check,
  are planned for 0.11.0.

## Defaults taken (reversible)

- The files-sensor overhead budget is not raised after three Windows CI measurements above it (6.07 to 6.53 against
  6.0 µs per event); a performance audit follows in 0.11.0.
- In-process plugin tests collect pending garbage before the run, so an earlier test's unclosed connection is not
  counted as opened before capture (#355).
