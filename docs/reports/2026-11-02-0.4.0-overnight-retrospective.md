## Outcome

## Worked

- **Fresh reviewer, then `/code-review xhigh`, then ponytail on every lane.** The reviewer approved G6 and the code
  review then found that quiet output hid failing gates. The code review also caught a secret leak in
  A-sqlalchemy-statistics (unmasked max-time SQL), and a GC-finalizer deadlock and a commit-before-commit bug in
  A-transactions. No single layer caught everything.
- **A real leased database.** The leased PostgreSQL run found a defect that every fake missed: `pg_stat_statements`
  created but not preloaded made the section FAILED.
- **The mechanical gate.** It replayed every red at its recorded SHA and refused faked reds, crash reds (11 in G1G2),
  red tests edited after their red commit, and missing evidence. Several refusals were real process failures.
- **WIP-commit and resume from handoff.md.** Every worker that hit a quota (Codex, both agy accounts, a hung
  subagent) was resumed by a fresh agent from the lane's handoff with no lost work.

## Didn't work (root cause → mechanism now in place)

| What | Root cause | Mechanism |
|---|---|---|
| Worker capacity collapsed after midnight | Codex hit its 5 h limit at 23:34; the Gemini 4 Argon weekly quota ran out on both agy accounts at 00:41 | Check capacity before every wave (`agent_capacity.py --refresh`); keep Claude subagents as the planned fallback, not an emergency |
| Foundation tests broke whenever a lane flipped its own flag | F's tests pinned "nothing implemented" (counts, `[-1]`, a hard-coded `data` plant) | `tests/surface.py` derives counts from the flags; the safety matrix takes per-lane rows from `tests/safety/test_<lane>_safety.py`; the flag-flip probe picks an unimplemented panel |
| The gate refused correct lanes for evidence format | The rules (Disposition column, `Red SHA` only on real red tables, `Implementer:` line, checklist paths) were learned during the night | The "Evidence format" and "Safety-matrix rows" sections in the briefs' COMMON.md; `handoff-template.md` |
| Gate replays ran in an environment without pytest, then without psycopg | The integration venv was synced before F added `psycopg[binary]`, and `uv run --frozen` did not install the test extra | `lane_gate.py` replays with `--frozen --extra test` (F-rest); re-sync the integration venv after any dependency merge |
| Overhead-budget tests failed under load all night, at the base too | Ten or more agents and suites on one machine | Paired, interleaved lane-vs-base isolation runs (coordinator script, ledger ruling), with an extended 6-pair measurement when unsure; budgets were never raised. Re-measure on a quiet machine before release |
| Aux gate runs repeated for evidence-only commits | Gate logs pin the head SHA | Re-stamp only when the delta is `.superpowers/` (or tests-only with an explicit, logged flag); otherwise re-run |
| A red test "passed" at its red commit | The Bash heredoc collapsed backslashes in a test string | Write test files with the Write/Edit tools, never a shell heredoc, when the content has backslashes |
