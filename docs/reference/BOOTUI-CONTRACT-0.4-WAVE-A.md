## 1. Data (Spring Data repository metadata)

### Endpoints and DTOs

- `GET /bootui/api/data/repositories`: no query/body. `RepositoriesReport` (`RepositoriesReport.java`) = `{springDataPresent:boolean,total:int,repositories:RepositoryDto[]}`. `RepositoryDto` (`RepositoryDto.java`) keys: `beanName,repositoryInterface,domainType,idType,storeModule,customImplementation,queryMethodCount,fragmentCount`; first six are strings (the latter five can be null), last two ints. Example: `{"springDataPresent":true,"total":1,"repositories":[{"beanName":"orderRepository","repositoryInterface":"com.acme.OrderRepository","domainType":"com.acme.Order","idType":"java.lang.Long","storeModule":"JPA","customImplementation":null,"queryMethodCount":1,"fragmentCount":0}]}`.
- `GET /bootui/api/data/repositories/{name}`: no query/body; name matches bean name, FQ interface name, or simple interface name; unknown gives 404 empty body. `RepositoryDetailDto` (`RepositoryDetailDto.java`) keys: `beanName,repositoryInterface,domainType,idType,storeModule,customImplementation,methods,fragments`; strings nullable except beanName/storeModule; arrays non-null. `RepositoryMethodDto` keys `name,signature,origin,query,nativeQuery,namedQuery`; query and namedQuery nullable strings; nativeQuery boolean. `origin` values: `FRAGMENT,QUERY,DEFAULT,CRUD,DERIVED,ANNOTATED`. Example: `{"beanName":"orderRepository","repositoryInterface":"com.acme.OrderRepository","domainType":"com.acme.Order","idType":"java.lang.Long","storeModule":"JPA","customImplementation":null,"methods":[{"name":"findOpen","signature":"List findOpen()","origin":"ANNOTATED","query":"select ...","nativeQuery":false,"namedQuery":null}],"fragments":[]}`. Java record components define the complete keys/types; the controller passes null for missing interface/domain/id/custom metadata.

## 2. Transactions

### Endpoints and DTOs

- `GET /transactions`: no query/body. `TransactionReport` keys (`TransactionReport.java`): `available:boolean,unavailableReason:string|null,capturing:boolean,bufferSize:int,totalCaptured:long,slowTransactionThresholdMillis:long,connectionHoldThresholdMillis:long,stats:TransactionStatsDto,entries:TransactionEntryDto[],warnings:string[]`. `TransactionStatsDto` keys (`TransactionStatsDto.java`): `totalTransactions,totalDurationMillis,maxDurationMillis,avgDurationMillis,slowTransactions,connectionHeldTransactions,committedCount,rolledBackCount,unknownCount,nestedCount,evicted`; counters long except average double. `TransactionEntryDto` keys (`TransactionEntryDto.java`): `id,methodName,propagation,isolation,status,startTimestamp,endTimestamp,durationMillis,parentId,thread,traceId,sqlStatementCount,connectionCount,readOnly,slow,connectionHeld,errorMessage`; timestamps are epoch ms, duration ms; `parentId` nullable Long, strings/references nullable; booleans and counts primitive. Status is a string; source defines values, not a Java enum. Example: `{"available":true,"unavailableReason":null,"capturing":true,"bufferSize":200,"totalCaptured":1,"slowTransactionThresholdMillis":200,"connectionHoldThresholdMillis":500,"stats":{"totalTransactions":1,"totalDurationMillis":3,"maxDurationMillis":3,"avgDurationMillis":3.0,"slowTransactions":0,"connectionHeldTransactions":0,"committedCount":1,"rolledBackCount":0,"unknownCount":0,"nestedCount":0,"evicted":0},"entries":[],"warnings":[]}`.

- `POST /transactions/recording`: optional `TransactionRecordingRequest {"enabled":boolean|null}`; absent/null behavior defaults to request's enabled value semantics in `TransactionsControllerSupport`; returns report.
- `GET /transactions/stream`: SSE, no query/body.
