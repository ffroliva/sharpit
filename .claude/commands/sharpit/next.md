# `/sharpit:next [feature]`

**Read `skills/status/SKILL.md` and follow its protocol now** (the `next` variant), passing `$ARGUMENTS` as given.

> Do **not** call `Skill(skill="status")`: the repo's `skills/*/SKILL.md` files are plain Markdown, not Skill-tool-invocable
> (only `.claude/commands/sharpit/*` are). Read the file directly.
